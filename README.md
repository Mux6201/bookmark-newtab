# 书签台 · 新标签页 (Bookmark Deck)

把浏览器书签整理成「抽屉卡片」的新标签页扩展。基于 **Manifest V3**,纯原生 HTML/CSS/JS 实现,**无构建步骤、无第三方运行时依赖**,克隆即可加载运行。

> 仅中文界面 · 目标浏览器:Chrome / Edge 等 Chromium 内核

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 抽屉式书签浏览 | 按书签文件夹分 tab 展示,超出宽度自动折叠进「更多」菜单 |
| 最常访问 | 主体内置顶分组,按点击次数展示 Top 常用书签;可隐藏单项,编辑模式下可恢复 |
| 点击排序 | 文件夹 tab 与主体分组都按组内点击总量降序排列,常用文件夹自动靠前 |
| 点击热力图 | GitHub 风格贡献图:近 15 周每天的点击总数,5 档色阶,悬停查看明细 |
| 点击热度 | 书签卡片按点击次数加深底色(四档),可在设置中关闭或清空统计 |
| 全局搜索 | 实时过滤标题 / 网址,按完整文件夹路径分组展示结果 |
| 回车搜索 | 搜索框回车或点击放大镜,用所选引擎(Google / 必应 / 百度 / DDG / 自定义)打开搜索 |
| 编辑模式 | 顶部铅笔图标进入,可改名、删除书签(直接调用 `chrome.bookmarks` API);删除只做局部 DOM 移除,不整页刷新 |
| 失效链接检测 | 逐个检测书签网址可达性,编辑模式下标出打不开的链接;结果缓存 6 小时,可强制重检 |
| 书签导入 | 解析浏览器导出的 Netscape 格式书签 HTML,批量写入书签树 |
| 主题系统 | 跟随系统 / 亮色 / 暗色,三套设计令牌(CSS 变量);6 种主题色可换 |
| 中文字体选择 | 扫描系统已安装字体,下拉内实时预览,即时切换 |
| 纸质视觉 | 自带纸颗粒纹理、暖橙印鉴点缀、亮/暗主题适配的「纸质 / 印鉴」设计风格 |
| 实时同步 | 监听 `chrome.bookmarks` 增删改移事件,自动刷新;删除走本地精准移除 |
| 自托管字体 | IBM Plex 字体随包打包(`css/fonts/`),离线可用,不依赖网络 |

## 安装

### 开发模式加载(Chrome / Edge)

1. 打开 `chrome://extensions`(Edge 为 `edge://extensions`)
2. 右上角开启 **开发者模式 (Developer mode)**
3. 点击 **加载已解压的扩展程序 (Load unpacked)**
4. 选择本项目根目录
5. 打开一个新标签页,即可看到书签台

无需 `npm install` 或任何编译步骤。

## 使用入门

- **搜索**:顶栏输入即过滤;回车或点击放大镜用默认搜索引擎搜索
- **编辑模式**:点右上角铅笔,卡片上出现编辑 / 删除按钮;再点一次铅笔退出
- **最常访问**:浏览模式下悬停卡片可点 × 隐藏;编辑模式下可恢复隐藏项
- **热力图**:点击右上角方格图标查看每日点击统计
- **设置**:右上角齿轮,可切主题、主题色、搜索引擎、中文字体、开关热度等

所有个性化数据都存在浏览器本地 `localStorage`,卸载扩展即清空,不外传任何数据。

## 项目结构

```
bookmark-newtab/
├── manifest.json            # MV3 清单:权限、newtab 覆盖、图标、favicon 资源
├── newtab.html              # 新标签页入口(所有 DOM 骨架都在这里)
├── css/
│   ├── style.css            # 全部样式 + 设计令牌(亮/暗双主题)
│   └── fonts/               # 自托管 IBM Plex 字体(无网络依赖)
├── js/
│   └── app.js               # 核心逻辑(单 IIFE,分区注释组织)
└── icons/                   # 扩展图标(16 / 48 / 128)
```

另有 `preview.html`(开发用预览页,内含模拟书签数据,不随扩展打包加载),便于不装扩展时在浏览器里直接调试 UI。

## 架构简述

```
newtab.html (DOM 骨架)
   └── js/app.js (单一 IIFE)
        ├── 数据层    getTree / walkTree / importHTML
        ├── 渲染层    renderTabs(自适应折叠) / renderGroups(分批渲染)
        ├── 交互层    搜索 / 编辑 / 设置 / 主题 / 热度 / 检测
        └── 持久化    localStorage(设置、点击统计、链接状态)
             └── chrome.bookmarks / chrome.favicon / chrome.webRequest
```

要点:

- **`allItems`**:全局唯一的拍平书签数组(`{ id, title, url, path[] }`),是搜索、分组、热度、检测的统一数据源
- **分批渲染**:卡片按每帧一批逐批填充,首屏不阻塞;搜索 / 删除等操作做局部 DOM 更新
- **排序**:tab 与分组均按「组内书签点击总量」降序,被「最常访问」隐藏的书签不计入
- **默认 favicon 检测**:预取 Chrome 默认占位图标做像素比对,与默认图一致时替换为首字母色块
- 更多实现细节(数据流、链接检测并发设计、历史技术债)见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取 / 创建 / 更新 / 删除书签,监听变更 |
| `favicon` | 通过 `_favicon/` 接口获取站点图标 |
| `webRequest` | 被动监听请求完成 / 失败,用于失效链接检测 |
| `host_permissions: <all_urls>` | favicon 与 webRequest 需要匹配所有网址 |

隐私说明:

- **无任何网络请求发往开发者服务器**,不存在统计 / 埋点
- `webRequest` 仅被动监听(`onCompleted` / `onErrorOccurred`),未申请 `webRequestBlocking`,不拦截、不修改任何流量
- 所有设置与统计数据存于本地 `localStorage`,随扩展卸载清空

## 开发与调试

- **页面调试**:在新标签页按 F12,直接调试 `newtab.html` 的 DOM 与 `app.js`
- **UI 预览**:浏览器直接打开 `preview.html`(内置模拟书签数据,无需加载扩展)
- **书签数据**:控制台调用 `chrome.bookmarks.getTree()` 查看原始书签树
- **扩展错误**:`chrome://extensions` → 本扩展的「错误」按钮
- **导入测试**:用浏览器导出的书签 HTML 作为导入样本

代码约定:纯原生实现、保持零运行时依赖、风格参考 `app.js`(IIFE + 分区注释)。
